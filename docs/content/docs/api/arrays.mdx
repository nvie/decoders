## array

<DecoderSig
  name="array"
  params="decoder: Decoder<T>, options?: SizeOptions"
  type="T[]"
  source="arrays.ts#L18-L50"
/>

Accepts arrays of whatever the given decoder accepts.

<DecoderPlayground
  decoder="array(string)"
  examples={["['hello', 'world']", '[]', "['hello', 1.2]"]}
/>

The optional `options` argument constrains the array's length. It accepts `min`, `max`, or
`size` (shorthand for an exact length), and is checked _before_ any item is decoded. See
[limiting array sizes](#limiting-array-sizes).

<DecoderPlayground
  decoder="array(string, { min: 1, max: 3 })"
  examples={["['hello', 'world']", '[]', "['a', 'b', 'c', 'd']", "['hello', 1.2]"]}
/>

## nonEmptyArray

<DecoderSig
  name="nonEmptyArray"
  params="decoder: Decoder<T>"
  type="[T, ...T[]]"
  source="arrays.ts#L52-L58"
/>

Like [`array()`][], but will reject arrays with 0 elements.  
Equivalent to `array(decoder, { min: 1 })`.

<DecoderPlayground
  decoder="nonEmptyArray(string)"
  examples={["['hello', 'world']", "['hello', 1.2]", '[]']}
/>

## poja

<DecoderSig name="poja" type="unknown[]" source="arrays.ts#L6-L16" />

Accepts any array, but doesn't validate its items further.

"poja" means "plain old JavaScript array", a play on [`pojo`][].

<DecoderPlayground
  decoder="poja"
  examples={["[1, 'hi', true]", "['hello', 'world']", '[]', '{}', "'hi'"]}
/>

## tuple

<DecoderSig

Accepts a tuple (an array with exactly _n_ items) of values accepted by the _n_ given
decoders.

  examples={["['hello', 1.2]", '[]', "['hello', 'world']", "['a', 1, 'c']"]}

## Limiting array sizes

<DecoderSig
  name="sized"
  params="decoder: Decoder<T[]>, options: SizeOptions"
  type="T[]"
  source="misc.ts#L35-L44"
/>

<Since version="2.9" />

Takes any array decoder and rejects values that don't match the given size constraints.
Also works with [strings][sized-strings] and [sets][sized-sets].

`SizeOptions` accepts `min`, `max`, or `size` (shorthand for exact length).

<DecoderPlayground
  decoder="sized(array(number), { min: 2, max: 4 })"
  examples={['[1, 2, 3]', '[1, 2]', '[1]', '[1, 2, 3, 4, 5]', '[]']}
/>

For arrays, prefer passing the options to [`array()`][] directly:

<DecoderPlayground
  decoder="array(number, { min: 2, max: 4 })"
  examples={['[1, 2, 3]', '[1, 2]', '[1]', '[1, 2, 3, 4, 5]', '[]']}
/>

`sized()` wraps the array decoder, so every item is decoded before the length is checked.
An out-of-range input then reports the first bad item instead of the length, and for large
inputs that error can be big. `array(decoder, options)` checks the length first.

[`array()`]: /array
[`pojo`]: /pojo
[sized-strings]: /docs/api/strings#limiting-string-size
[sized-sets]: /docs/api/sets-and-maps#limiting-set-sizes
