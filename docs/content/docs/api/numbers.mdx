## number

<DecoderSig name="number" type="number" source="numbers.ts#L29-L37" />

Accepts only finite numbers (e.g. -3.14, 0, 1, 42, ...). Integers or floats, but not `NaN`
or `Infinity`.

<DecoderPlayground
  decoder="number"
  examples={['123', '-3.14', 'Infinity', 'NaN', "'not a number'"]}
/>

## integer

<DecoderSig name="integer" type="number" source="numbers.ts#L39-L55" />

Accepts only integers (e.g. ..., -2, -1, 0, 1, 2, ...). Whole numbers, and safe (between
-(2^53-1) and 2^53-1).

<DecoderPlayground
  decoder="integer"
  examples={['123', '-3.14', '2 ** 53', 'Infinity', 'NaN', "'not a integer'"]}
/>

## anyNumber

<DecoderSig name="anyNumber" type="number" source="numbers.ts#L17-L27" />

Accepts any valid `number` value.

This also accepts special values like `NaN` and `Infinity`, and unsafe integers (beyond
±(2^53-1)). Unless you want to deliberately accept those, you'll likely want to use the
[`number`][] or [`integer`][] decoder instead.

<DecoderPlayground
  decoder="anyNumber"
  examples={['123', '-3.14', 'Infinity', 'NaN', "'not a number'"]}
/>

## Limiting number ranges

Every number decoder can be called with range options, to put the bounds right next to the
type. `min` and `max` are inclusive, `gt` and `lt` are exclusive.

<DecoderPlayground
  decoder={[
    ['number({ min: 0 })', 'number({ min: 0 })'],
    ['number({ max: 100 })', 'number({ max: 100 })'],
    ['number({ gt: 0, lt: 100 })', 'number({ gt: 0, lt: 100 })'],
    ['integer({ min: 1, max: 100 })', 'integer({ min: 1, max: 100 })'],
  ]}
  examples={['42', 'Math.PI', '0', '100', '-1', '123']}
/>

<Since version="2.9" />

Deprecated in 3.0. Use the range options instead:

| Deprecated                | Use instead                    |
| :------------------------ | :----------------------------- |
| `min(0)`                  | `number({ min: 0 })`           |
| `max(100, integer)`       | `integer({ max: 100 })`        |
| `between(1, 10)`          | `number({ min: 1, max: 10 })`  |
| `between(1, 10, natural)` | `natural({ min: 1, max: 10 })` |
