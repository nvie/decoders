## number

<DecoderSig name="number" type="number" source="numbers.ts#L16-L23" />

Accepts only finite numbers (e.g. -3.14, 0, 1, 42, ...). Integers or floats, but not `NaN`
or `Infinity`.

<DecoderPlayground
  decoder="number"
  examples={['123', '-3.14', 'Infinity', 'NaN', "'not a number'"]}
/>

## integer

<DecoderSig name="integer" type="number" source="numbers.ts#L25-L32" />

Accepts only integers (e.g. ..., -2, -1, 0, 1, 2, ...). Whole numbers, and finite.

  decoder="integer"
  examples={['123', '-3.14', 'Infinity', 'NaN', "'not a integer'"]}

## anyNumber

<DecoderSig name="anyNumber" type="number" source="numbers.ts#L5-L14" />

Accepts any valid `number` value.

This also accepts special values like `NaN` and `Infinity`. Unless you want to
deliberately accept those, you'll likely want to use the [`number`][] decoder instead.

<DecoderPlayground
  decoder="anyNumber"
  examples={['123', '-3.14', 'Infinity', 'NaN', "'not a number'"]}
/>

## Limiting number ranges

<DecoderSig
  name="min"
  params="min: number, decoder?: Decoder<number>"
  type="number"
  source="numbers.ts#L57-L67"
/>
<DecoderSig
  name="max"
  params="max: number, decoder?: Decoder<number>"
  type="number"
  source="numbers.ts#L69-L79"

<DecoderSig
  name="between"
  params="min: number, max: number, decoder?: Decoder<number>"
  multiline
  type="number"
  source="numbers.ts#L81-L99"
/>

<Since version="2.9" />

Rejects values outside the given bounds. Bounds are inclusive. Defaults to the `number`
decoder if none is provided.

<DecoderPlayground
  decoder={[
    ['min', 'min(0)'],
    ['max', 'max(100)'],
    ['between', 'between(0, 100)'],
  ]}
  examples={['42', 'Math.PI', '100', '-1', '123']}
/>

You can pass `integer` as the number decoder to use to further restrict what kind of
numbers are accepted:

<DecoderPlayground
  decoder={[
    ['between(1, 100)', 'between(1, 100)'],
    ['between(1, 100, integer)', 'between(1, 100, integer)'],
  ]}
  examples={['5', '3.14', 'Math.PI * 100']}
/>
